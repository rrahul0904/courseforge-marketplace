# CourseForge Marketplace

Canonical repository for the CourseForge multi-instructor learning marketplace.

CourseForge is a clean-room product inspired by public creator-platform and marketplace patterns. It owns instructor commerce, course publishing, checkout, entitlements, learning delivery, reviews, certificates and payouts. Academic OS remains a separate student workflow product.

Implementation work is developed through pull requests; production readiness is not claimed until hosted infrastructure and release evidence are complete.
